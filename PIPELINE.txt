skimflow: pipeline overview
===========================

Input:  paired-end / single-end Illumina genome-skim reads, or long reads
Output: read QC reports, genome-size + coverage estimate, de novo assembly +
        contig stats, mitogenome + annotation, per-gene mito multi-FASTAs,
        mitochondrial phylogenies (nt + aa), BUSCO marker scores, a
        per-sample metrics table, single-page MultiQC HTML report

A sample is short-read OR long-read, never both. Short-read samples take the
RESPECT / GetOrganelle / annotation / phylogeny path; long-read samples take
Filtlong + Flye. Both tracks rejoin at BUSCO and the contig stats, and feed one
report.


Input modes (mutually exclusive)
--------------------------------

  --input samplesheet.csv           multi-sample; columns sample_id, fastq_1,
                                    fastq_2, species_id, expected_genome_size_bp
                                    (short rows) or long_reads, lr_type (long rows)
  --r1 R1.fq.gz [--r2 R2.fq.gz]     one short-read sample (sample_id derived
                                    from the R1 file name unless --sample_id)
  --long_reads reads.fq.gz          one long-read sample (--lr_type nanopore|pacbio)


Workflow graph
--------------

  parseSamplesheet / --r1 / --long_reads  -> channel of (meta, reads | long_reads)
        |
        +================ short-read track ================
        |
        v
  READ_QC (fastp)
        |
        v
  DECONTAM (kraken2)        [optional, --kraken2_db]
        |  (clean reads)
        +--> GENOME_SIZE (RESPECT)                          [skip: --skip_respect]
        |        (genome size + coverage, skim-aware)
        |
        +--> ASSEMBLY (MEGAHIT) ----------------+
        |                                       |
        +--> MITO (GetOrganelle)                |
        |        ^                              |
        |     MITO_DB (downloaded once)         |
        |        |                              |
        |        v                              |
        |   MITOGENOME_ANNOTATION               |
        |     (MitoZ + MITOS2)                  |
        |        ^                              |
        |     MITOS2_DB (downloaded once)       |
        |        |                              |
        |        v                              |
        |   MITO_GENES                          |
        |     GENE_HARVEST (per sample)         |
        |        -> GENE_AGGREGATE (once)       |
        |        (per-gene multi-FASTAs +       |
        |         occupancy matrix)             |
        |        |                              |
        |        v                              |
        |   PHYLOGENY  [skip: --skip_phylo]     |
        |     ALIGN (MAFFT) -> TRIM (trimAl)    |
        |       -> GENE_TREE (IQ-TREE, per gene)|
        |       -> CONCAT -> SUPER_TREE         |
        |          (IQ-TREE) -> TREE_PLOT       |
        |                                       |
        +================ long-read track ======|=========
        |                                       |
        v                                       |
  LR_QC (Filtlong)                              |
        |                                       |
        v                                       |
  FLYE -----------------------------------------+
                                                |
                                                v
                              MARKERS (BUSCO)  [MARKER_EXTRACTION]
                                  ^   (short + long contigs mixed)
                              BUSCO_DB (downloaded once)

                              ASSEMBLY_STATS (contig stats per assembly)

  SUMMARY_METRICS (once)
      joins: fastp.json + RESPECT summary + assembly stats + GetOrganelle /
             MitoZ / MITOS2 summaries + gene occupancy + BUSCO short_summary
             + samplesheet metadata -> skimflow_metrics.csv

  REPORT (MultiQC)
      collects: fastp.json + RESPECT summary + BUSCO short_summary +
                kraken2 report + mitogenome/annotation summaries +
                mito gene-occupancy table + phylogeny tables and tree
                figures + the per-sample metrics table


Steps and tools
---------------

1. READ_QC                   modules/read_qc.nf
   Tool:      fastp (run with its default trimming/filtering settings)
   Container: quay.io/biocontainers/fastp:1.3.3--h43da1c4_0
   Purpose:   adapter trimming + quality filtering of raw FASTQs. Only the
              JSON/HTML reports are published; the trimmed FASTQs are kept
              with --save_trimmed_reads.

2. DECONTAM (optional)       modules/decontam.nf
   Tool:      kraken2
   Container: quay.io/biocontainers/kraken2:2.1.6--pl5321h077b44d_0
   Enable:    --kraken2_db /path/to/k2_db   (short-read only)
   Purpose:   classify reads against a kraken2 DB, keep the unclassified
              (target) reads as the clean set feeding the steps below

3. GENOME_SIZE               modules/genome_size.nf
   Tool:      RESPECT (Sarmashghi et al. 2021, PLOS Comput Biol)
   Container: local/respect:0.2  (custom, built from
              containers/respect/Containerfile, see below)
   Skip:      --skip_respect (also implicit for long-read-only runs)
   Purpose:   skim-data-specific estimator that produces both
              genome size (bp) AND sequencing coverage (x) from the
              k-mer profile, with repeat correction. Coverage is reported
              per sample in the MultiQC report and the metrics table as a
              data-quality indicator; it does not gate downstream steps,
              which run in parallel regardless.
   Output:    estimated-parameters.txt (RESPECT native),
              <id>.genome_size.txt, <id>.coverage.txt,
              <id>_respect_mqc.tsv (MultiQC custom-content table),
              respect_run.log
   Note:      RESPECT requires the Gurobi optimisation solver. The custom
              container is python:3.8-slim + apt jellyfish (RESPECT's k-mer
              counter) + pip RESPECT (pinned GitHub commit) and gurobipy.
              A free academic Gurobi WLS licence is mounted at runtime,
              never baked in. Get one at https://www.gurobi.com/academia/
              and save to ~/gurobi.lic (or set GUROBI_LIC=...).

4. ASSEMBLY                  modules/assembly.nf
   Tool:      MEGAHIT   (short-read track)
   Container: quay.io/biocontainers/megahit:1.2.9--haf24da9_8
   Preset:    --megahit_preset, default meta-sensitive

   FLYE                      modules/flye.nf
   Tool:      Flye      (long-read track, after LR_QC / Filtlong)
   Container: quay.io/biocontainers/flye:2.9.6--py313h7fbb527_1
   LR_QC:     quay.io/biocontainers/filtlong:0.3.1--h077b44d_0

   ASSEMBLY_STATS            modules/summary_metrics.nf
   Purpose:   n contigs, total bp, N50, largest contig per assembly
              (both tracks), written to <id>.assembly_stats.tsv

5. MITO                      modules/mitogenome.nf
   Subworkflow: MITO_DB -> MITOGENOME
   Tool:      GetOrganelle
   Container: quay.io/biocontainers/getorganelle:1.7.7.1--pyhdfd78af_0
   Note:      short-read only. On exit codes 130-143 (OOM / walltime kill)
              it retries up to 3 times with 16 GB x attempt memory, then
              ignores the failure so one sample cannot stop the run.

6. MITOGENOME_ANNOTATION     modules/mitogenome_annotation.nf
   Tools:     MitoZ + MITOS2  (run on the GetOrganelle mitogenome FASTA)
   Containers: docker.io/guanliangmeng/mitoz:3.6
               quay.io/biocontainers/mitos:2.1.10--pyhdfd78af_0
   MITOS2_DB: downloads the MITOS2 reference data (refseq89m) once,
              unless --mitos2_refdir is set
   Defaults:  annelid mt (MitoZ clade Annelida-segmented-worms, genetic
              code 5); override with --mitoz_clade / --mitoz_genetic_code /
              --mitos2_genetic_code (e.g. Chordata + code 2 for vertebrates).

7. MITO_GENES                modules/mito_genes.nf
   Tool:      bundled parsers bin/harvest_mito_genes.py +
              bin/aggregate_mito_genes.py (stdlib only)
   Container: docker.io/library/python:3.12
              (full image, not -slim: Nextflow needs `ps`/procps)
   GENE_HARVEST (per sample): parse each sample's MITOS2 result.fas /
              result.faa, normalise gene names, keep the 13 PCGs + 16S/12S,
              resolve duplicate copies and strand-aware rRNA fragments,
              write one FASTA per gene + a per-sample occupancy row.
              errorStrategy 'ignore' (a sample that did not annotate
              contributes nothing).
   GENE_AGGREGATE (once): pool every sample's genes into one multi-FASTA
              per gene (nt/<GENE>.fasta, aa/<GENE>.faa), the gene-by-sample
              occupancy matrix, and a MultiQC custom-content table.
   Purpose:   give phylogenetics one alignment input per gene; stays useful
              when a full mitogenome assembly is too fragmentary.

8. PHYLOGENY                 modules/phylogeny.nf
   Tools:     MAFFT (--mafft_args, default --auto), trimAl (--trimal_mode,
              default automated1), IQ-TREE 2 (ModelFinder, UFBoot + SH-aLRT,
              fixed --iqtree_seed), bin/concat_alignments.py,
              bin/tree_to_svg.py
   Containers: quay.io/biocontainers/mafft:7.525--h031d066_1
               quay.io/biocontainers/trimal:1.5.1--h9948957_0
               quay.io/biocontainers/iqtree:2.3.6--h503566f_1
               docker.io/library/python:3.12 (CONCAT, TREE_PLOT)
   Skip:      --skip_phylo
   Purpose:   per gene and per sequence type (nt: 13 PCG + 2 rRNA, aa:
              13 PCG): align, trim, optional gene tree; then concatenate
              into a partitioned supermatrix (genes in fewer than
              --phylo_min_taxa_per_gene samples dropped) and build an
              unrooted ML species tree. Any tree with fewer than 4 taxa is
              skipped with a note instead of failing the run.

9. MARKER_EXTRACTION         modules/markers.nf
   Subworkflow: BUSCO_DB -> MARKERS
   Tool:      BUSCO
   Container: quay.io/biocontainers/busco:6.0.0--pyhdfd78af_3
   Mode:      genome (run on MEGAHIT and Flye contigs), lineage
              --busco_lineage (default metazoa_odb10)

10. SUMMARY_METRICS          modules/summary_metrics.nf
   Tool:      bin/collect_metrics.py (stdlib only)
   Container: docker.io/library/python:3.12
   Output:    summary/skimflow_metrics.csv, one row per sample across all
              stages, plus a MultiQC custom-content table

11. REPORT                   modules/report.nf
   Tool:      MultiQC
   Container: quay.io/biocontainers/multiqc:1.34--pyhdfd78af_0


Container engines
-----------------

Combinable engine profiles (pick one for local runs):
  -profile podman       conf/podman.config       (--userns=keep-id + Gurobi licence bind)
  -profile docker       conf/docker.config       (-u <uid:gid>     + Gurobi licence bind)
  -profile apptainer    conf/apptainer.config    (Gurobi licence bind)

Site profile (self-contained, includes apptainer + SLURM):
  -profile gwdg         conf/gwdg.config         (env-var driven)

Convenience profiles:
  -profile test         conf/test.config         (5 annelid skims, assets/samplesheet_test.csv)
  -profile smoke        conf/smoke.config        (1 fish skim, assets/samplesheet_smoke.csv)

All engine profiles auto-bind a Gurobi licence file from
$GUROBI_LIC (default ~/gurobi.lic) into /opt/gurobi/gurobi.lic
inside the container, so RESPECT finds it. If the file does not
exist, the bind is silently skipped and RESPECT errors at runtime
with a "no licence" message.


One-time setup before first run
-------------------------------

  # 1. Get a free Gurobi academic WLS licence:
  #    https://www.gurobi.com/academia/  ->  save to ~/gurobi.lic

  # 2. Build the RESPECT container:
  podman build -t local/respect:0.2 -f containers/respect/Containerfile containers/respect
  # or, on GWDG (scripts/run_gwdg.sh does this for you):
  apptainer build $APPTAINER_CACHEDIR/respect_0.2.sif containers/respect/respect.def

  # 3. Fetch test data:
  ./scripts/fetch_test_data.sh --manifest assets/test_manifest.tsv

  # 4. Run:
  nextflow run . -profile test,podman


Helper scripts
--------------

  scripts/fetch_test_data.sh   Subsamples public paired-end ENA runs into
                               test_data/: one run (default DRR148567,
                               Bostrychus sinensis, 50k pairs; smoke profile)
                               or every row of a manifest (--manifest
                               assets/test_manifest.tsv; test profile)

  scripts/run_gwdg.sh          GWDG launcher: loads modules, installs
                               Nextflow, finds or allocates the workspace,
                               builds the RESPECT .sif, checks the Gurobi
                               licence, then runs -profile gwdg (--help)

  bootstrap_gwdg.sh            Clones or updates the repo on GWDG, then
                               hands off to scripts/run_gwdg.sh

  benchmarks/run_titration.sh  Coverage-titration benchmark: down-samples one
                               high-coverage sample with rasusa and runs the
                               pipeline at each level (--help)

  bin/*.py                     Stdlib helpers called by the processes:
                               harvest_mito_genes.py, aggregate_mito_genes.py,
                               concat_alignments.py, tree_to_svg.py,
                               collect_metrics.py (unit tests in tests/)
