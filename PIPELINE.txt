skimflow: pipeline overview
===========================

Input:  paired-end / single-end Illumina genome-skim reads, or long reads
Output: trimmed reads, genome-size + coverage estimate, de novo assembly,
        mitogenome + annotation, per-gene mito multi-FASTAs, BUSCO marker
        scores, single-page MultiQC HTML report

A sample is short-read OR long-read, never both. Short-read samples take the
RESPECT / GetOrganelle / annotation path; long-read samples take Filtlong +
Flye. Both tracks rejoin at BUSCO and feed one report.


Workflow graph
--------------

  samplesheet.csv  (sample_id, fastq_1, fastq_2, species_id,
                    expected_genome_size_bp; or long_reads, lr_type)
        |
        v
  parseSamplesheet  -> channel of (meta, reads | long_reads)
        |
        +================ short-read track ================
        |
        v
  READ_QC (fastp)
        |
        v
  DECONTAM (kraken2)        [optional, --kraken2_db]
        |  (clean reads)
        +--> GENOME_SIZE (RESPECT)                          [skip: --skip_respect]
        |        (genome size + coverage, skim-aware)
        |
        +--> ASSEMBLY (MEGAHIT) ----------------+
        |                                       |
        +--> MITO (GetOrganelle)                |
        |        ^                              |
        |     MITO_DB (downloaded once)         |
        |        |                              |
        |        v                              |
        |   MITOGENOME_ANNOTATION               |
        |     (MitoZ + MITOS2)                  |
        |        |                              |
        |        v                              |
        |   MITO_GENES                          |
        |     GENE_HARVEST (per sample)         |
        |        -> GENE_AGGREGATE (once)       |
        |        (per-gene multi-FASTAs +       |
        |         occupancy matrix)             |
        |                                       |
        +================ long-read track ======|=========
        |                                       |
        v                                       |
  LR_QC (Filtlong)                              |
        |                                       |
        v                                       |
  FLYE -----------------------------------------+
                                                |
                                                v
                              MARKERS (BUSCO)  [MARKER_EXTRACTION]
                                  ^   (short + long contigs mixed)
                              BUSCO_DB (downloaded once)

  All per-sample outputs --> REPORT (MultiQC)
      collects: fastp.json + RESPECT summary + BUSCO short_summary +
                kraken2 report + mitogenome/annotation summaries +
                mito gene-occupancy table


Steps and tools
---------------

1. READ_QC                   modules/read_qc.nf
   Tool:      fastp
   Container: quay.io/biocontainers/fastp:1.3.3--h43da1c4_0
   Purpose:   adapter trimming + quality filtering of raw FASTQs

2. DECONTAM (optional)       modules/decontam.nf
   Tool:      kraken2
   Container: quay.io/biocontainers/kraken2:2.1.6--pl5321h077b44d_0
   Enable:    --kraken2_db /path/to/k2_db   (short-read only)
   Purpose:   classify reads against a kraken2 DB, keep the unclassified
              (target) reads as the clean set feeding the steps below

3. GENOME_SIZE               modules/genome_size.nf
   Tool:      RESPECT (Sayyari et al. 2022)
   Container: local/respect:0.2  (custom, built from
              containers/respect/Containerfile, see below)
   Skip:      --skip_respect (also implicit for long-read-only runs)
   Purpose:   skim-data-specific estimator that produces both
              genome size (bp) AND sequencing coverage (×) from the
              raw k-mer profile, with repeat correction. Coverage is
              the go/no-go signal; if it's too low, abort before
              spending compute on assembly/markers.
   Output:    estimated-parameters.txt (RESPECT native),
              <id>.genome_size.txt, <id>.coverage.txt,
              <id>_respect_mqc.tsv (MultiQC custom-content table)
   Note:      RESPECT requires the Gurobi optimisation solver. We
              ship a custom container (micromamba + RESPECT + Gurobi)
              and mount a free academic Gurobi WLS licence at
              runtime. Get one at https://www.gurobi.com/academia/
              and save to ~/gurobi.lic (or set GUROBI_LIC=...).

4. ASSEMBLY                  modules/assembly.nf
   Tool:      MEGAHIT   (short-read track)
   Container: quay.io/biocontainers/megahit:1.2.9--haf24da9_8
   Preset:    --megahit_preset, default meta-sensitive

   FLYE                      modules/flye.nf
   Tool:      Flye      (long-read track, after LR_QC / Filtlong)
   Container: quay.io/biocontainers/flye:2.9.6--py313h7fbb527_1
   LR_QC:     quay.io/biocontainers/filtlong:0.3.1--h077b44d_0

5. MITO                      modules/mitogenome.nf
   Subworkflow: MITO_DB -> MITOGENOME
   Tool:      GetOrganelle
   Container: quay.io/biocontainers/getorganelle:1.7.7.1--pyhdfd78af_0
   Note:      short-read only; errorStrategy 'ignore' so it fails
              gracefully at low coverage.

6. MITOGENOME_ANNOTATION     modules/mitogenome_annotation.nf
   Tools:     MitoZ + MITOS2  (run on the GetOrganelle mitogenome FASTA)
   Containers: docker.io/guanliangmeng/mitoz:3.6
               quay.io/biocontainers/mitos:2.1.10--pyhdfd78af_0
   Defaults:  invertebrate mt (clade Arthropoda, genetic code 5);
              override with --mitoz_clade / --mitoz_genetic_code /
              --mitos2_genetic_code for vertebrates.

7. MITO_GENES                modules/mito_genes.nf
   Tool:      bundled parsers bin/harvest_mito_genes.py +
              bin/aggregate_mito_genes.py (stdlib only)
   Container: docker.io/library/python:3.12
              (full image, not -slim: Nextflow needs `ps`/procps)
   GENE_HARVEST (per sample): parse each sample's MITOS2 result.fas /
              result.faa, normalise gene names, keep the 13 PCGs + 16S/12S,
              resolve duplicate copies and strand-aware rRNA fragments,
              write one FASTA per gene + a per-sample occupancy row.
              errorStrategy 'ignore' (a sample that did not annotate
              contributes nothing).
   GENE_AGGREGATE (once): pool every sample's genes into one multi-FASTA
              per gene (nt/<GENE>.fasta, aa/<GENE>.faa), the gene-by-sample
              occupancy matrix, and a MultiQC custom-content table.
   Purpose:   give phylogenetics one alignment input per gene; stays useful
              when a full mitogenome assembly is too fragmentary.

8. MARKER_EXTRACTION         modules/markers.nf
   Subworkflow: BUSCO_DB -> MARKERS
   Tool:      BUSCO
   Container: quay.io/biocontainers/busco:6.0.0--pyhdfd78af_3
   Mode:      genome (run on MEGAHIT and Flye contigs)

9. REPORT                    modules/report.nf
   Tool:      MultiQC
   Container: quay.io/biocontainers/multiqc:1.34--pyhdfd78af_0


Container engines
-----------------

Combinable engine profiles (pick one for local runs):
  -profile podman       conf/podman.config       (--userns=keep-id + Gurobi licence bind)
  -profile docker       conf/docker.config       (-u <uid:gid>     + Gurobi licence bind)
  -profile apptainer    conf/apptainer.config    (Gurobi licence bind)

Site profile (self-contained, includes apptainer + SLURM):
  -profile gwdg         conf/gwdg.config         (env-var driven)

Convenience profile:
  -profile test         conf/test.config         (uses assets/samplesheet_test.csv)

All engine profiles auto-bind a Gurobi licence file from
$GUROBI_LIC (default ~/gurobi.lic) into /opt/gurobi/gurobi.lic
inside the container, so RESPECT finds it. If the file does not
exist, the bind is silently skipped and RESPECT errors at runtime
with a "no licence" message.


One-time setup before first run
-------------------------------

  # 1. Get a free Gurobi academic WLS licence:
  #    https://www.gurobi.com/academia/  ->  save to ~/gurobi.lic

  # 2. Build the RESPECT container:
  podman build -t local/respect:0.2 -f containers/respect/Containerfile containers/respect
  # or, on GWDG:
  apptainer build $APPTAINER_CACHEDIR/respect_0.2.sif containers/respect/respect.def

  # 3. Fetch test data:
  ./scripts/fetch_test_data.sh

  # 4. Run:
  nextflow run . -profile test,podman


Helper scripts
--------------

  scripts/fetch_test_data.sh   Subsamples real ENA reads (default DRR148567,
                               Bostrychus sinensis, 50k pairs) into test_data/

  ~/bin/gnu-shim/date          Symlink to /usr/bin/gnudate, prepended to PATH
                               in ~/.bashrc; works around uutils-coreutils
                               on Ubuntu 25 breaking Nextflow's nxf_date.
